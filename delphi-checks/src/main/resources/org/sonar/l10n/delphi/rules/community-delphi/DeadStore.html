Why is this an issue?

Dead stores refer to assignments made to local variables that are subsequently never used or immediately overwritten. Such assignments are unnecessary and impact the clarity and potentially performance of the code. Removing them improves clarity, intentionality, and readability.

There are cases where a clean removal isn't known to be safe. For example, if a variable is assigned to the result of a function, it is unknown if the function has side effects. If the function is pure, it is safe to remove.

Exceptions

This rule ignores initializations to -1, 0, 1, nil, True, False, [], and ''.

How to fix it

Remove the unnecessary assignment. 

function Test(Y: Integer): Integer;
begin
  var I := 100; // Noncompliant
  I := 150; // Noncompliant
  I := 200;
  Exit(I + Y);
end;

Compliant solution

function Test(Y: Integer): Integer;
begin
  var I := 200; // Compliant: no unnecessary assignment
  Exit(I + Y);
end;
