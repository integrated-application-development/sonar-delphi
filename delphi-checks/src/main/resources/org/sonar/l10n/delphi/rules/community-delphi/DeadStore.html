Why is this an issue?

Dead stores refer to assignments made to variables that are subsequently never used or immediately overwritten. Such assignments are unnecessary and impact the clarity and potentially performance of the code. Removing them improves clarity, intentionality, and readability.

How to fix it

Remove the unnecessary assignment. 

function Test(Y: Integer): Integer;
begin
  var I := 100; // Noncompliant
  I := 150; // Noncompliant
  I := 200;
  Exit(I + Y);
end;

Compliant solution

function Test(Y: Integer): Integer;
begin
  var I := 200; // Compliant: no unnecessary assignment
  Exit(I + Y);
end;
